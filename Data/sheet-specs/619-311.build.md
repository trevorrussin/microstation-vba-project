# 619-311 — live build playbook

Durable tips and preferences for Multilane Undivided Right Lane Closure
(Short Term). Machine-enforced prefs live in `619-311.json`
(`annotationStyle`, `symbols.channelizingDevices.representation`,
`annotations`, `rules`). This file is the human/agent checklist so the next
build does not rediscover the same gotchas from `agent-log.md`.

**Authority order (never reverse):** official NYSDOT PDF → this sheet JSON →
this playbook → engineer chat hints.

Source PDF: see `sheet.sourceUrl` / `sheet.localPdf` in `619-311.json`.

---

## Preferred call path

### Named sheet (always)

1. Call `get_required_designer_inputs("619-311")`. Ask once per `toAsk`
   item using those `askUserChoice` options. Do not invent speed or area
   type. Do not offer 60 mph (sheet max 55). Apply `derived` (closure type,
   NON-FREEWAY sign class) and cite them. Skip `locked`. If
   `highwayCaution.mismatch` is true (placed road is divided/freeway/TWLT
   /ramp), caution and ask — do not build on the wrong highway.
2. `get_sheet_requirements("619-311")` — read `buildGuide` / `buildGuidePath`
   on the response (this file).
3. `get_sheet_build_guide("619-311")` if you need a fresh full copy mid-turn.
4. `build_wztc_order_table(..., sheet_num="619-311", area_type=...)` — show
   the engineer the walk before drawing.
5. `propose_corridor_source` then `lock_corridor_path` (last placed /
   click roadway / level / points last). Travel only if unclear, with
   real endpoints. Closed side = right of travel on this sheet (do not
   ask). Then `propose_work_area_on_path` + `snap_work_area_to_path` —
   picks snap to the path (station only). If the path is shorter than
   the resolved approach, stop with numbers and offer to extend.
6. `resolve_sheet_lateral(up, dn, closed_side, real_road_edge=…,
   path_vertices=…)` — locks `outward_sign` / `half_len` /
   `closed_outward` (real EOP = lane+shoulder). Align2 G20-2 uses the
   same closed shoulder as Align1.
7. `run_sheet_build(upstream_edge, downstream_edge, path_vertices=…)` —
   preferred one-shot (uses locked lateral). Corridor,
   hatch, cones, PV/AP follow the path; **sign faces stay view-horizontal**
   (do not rotate lettering to the corridor tangent). **TWZSGN_P posts
   rotate with travel** (T on the tangent; arm downstream). For a cheap try
   without wiping a kept corridor: `begin_sheet_sandbox` /
   `run_sheet_build_sandbox` (offset Y band), then `keep_sheet_sandbox`
   or `revert_sheet_sandbox`.
8. On `status=ERROR`, follow `phases[].replan` / `reflect_sheet_build` —
   do **not** clear and restart unless the replan says so.
9. Confirm `get_geometry_scorecard().passed` (geometry-faithful), review QA
   frames, fix with IDs/ranges (no stacked duplicates), then FINAL.

### Real-road combo (striped corridor + this sheet)

When the engineer wants WZTC on a real undivided multilane (not abstract
ticks only), after step 7:

10. Re-place striping **after** `run_sheet_build` if `force` / clear wiped
    journal-owned `place_polyline` roads — e.g.
    `place_two_way_highway(4, …, vertices=path_vertices, side="right")` on
    curved roads, or `(x1, y_north_outer, x2, y_north_outer, …)` on a
    straight band. `(x1,y1)` / first vertex is the **first travel OUTER
    EDGE**, not yellow center. Do **not** skip striping when the engineer
    asked for a real multilane / “four-way road.”
11. `delete_construction_guides()` — removes ONLY white alignment lines +
    perp ticks. Do not delete signs/cones/hatch/dims/AP/PV/striping.
12. Verify: one arrow panel; G20-2 tip on closed-shoulder EOP with W20s;
    hatch in closed lane; scorecard pass; then FINAL.

Helper (scripted smoke): `scripts/build_619311_on_real_road.py` —
Urban 55, EB right, `half_len=20`, north-outer band in the script header.

Outside a named sheet plan, the checklist does not apply (general CAD).

## Signs and symbols

- Resolve every sheet sign via `resolve_sign_code` before `place_sign`.
- Typical roadside set (legend/side variants after resolve): W4-2R family,
  W20-5R family, W20-1R family, G20-2 (END ROAD WORK). Exact codes come
  from the locked order table / spec — do not invent.
- **NYW8-33** ("LANE CLOSED") is **vehicle-mounted** on the protective
  vehicle (`symbols` → `protectiveVehicle1.carriesSign`). Hand off mounting
  if there is no headless attach path — do **not** invent a roadside
  SignLibrary substitute or declare the plan complete while pretending it
  was placed as a post.
- After each roadside assembly: `set_sign_attributes` only. Never paint face
  cells Color=0/6 or Weight=3 (bleaches orange/yellow faces).
- **G20-2 label:** two lines like every other MUTCD sign — `G20-02` above
  `36" x 18"`. Face already shows END ROAD WORK; that does **not** replace
  the code/size callout (`signs.items[G20-2].labelNote`).
- **G20-2 face symbology:** black lettering, orange field, **black** SF_P
  inner hole (color 240), orange outer. If the hole is orange, the face is
  wrong — `DrawSign.FixG20FaceBlackHole` must have run (`faceSymbologyNote`).
- **Arrow panel:** `place_cell_on_post` with base at the station **perp tip**,
  stem + panel only (no TWZSGN_P — stacks on the tip cone). Default
  `half_len=40` for abstract ticks; real-road demo uses closed lane +
  shoulder (e.g. 12+8 → 20) so the tip sits on outer EOP. Compiler emits
  tip base + outward dir; label beyond the panel. See
  `symbols.items[arrowPanel].mountingStyleNote`.
- PV front meets roll-ahead upstream end (see
  `protectiveVehicle1.stationAnchorNote` in the JSON).
- **EB right (south) closure:** Align1 stations increase **upstream**
  (west, tan=−X). `outward_sign=+1` maps to south (−Y). `outward_sign=−1`
  hatches the north/left lane — wrong for EB right. Helper:
  `scripts/build_619311_on_real_road.py` (demo only; place striping
  **after** `run_sheet_build` so `force` wipe does not delete the road).

## Corridor / stations

- Prefer `assemble_corridor` / `run_sheet_build` over freestyle
  `define_alignment_segment` + `commit_alignment`.
- Upstream and Downstream are **two** work-area edges; Downstream must not
  be committed further along Upstream's own line
  (`check_corridor_topology` / rules gate).
- `cross_validate_stations` must pass before trusting geometry (auto from
  stations / `place_sheet_geometry` unless `force=True`).
- Do not invent order-table rows the sheet lacks (no Vehicle Space,
  no Upstream Barrier / Box Beam just because `GetDefaultUpstreamItems`
  used to emit them — see `knownCodeDeviations`).

## Annotation / visual style (engineer-approved)

Reference: engineer hand-drawn strip ~Y 214k; styled rebuild used Y=232000
(`scripts/rebuild_619311_styled.py`).

- Dimension **every** consecutive tick span (tip-to-tip); length text on the
  dim (`ny_Plan` / `ExecPlaceDimension` path via compiler).
- Name labels **below** only for sheet-required features (`annotations`).
- SHOULDER TAPER: overlay dim + label on the **opposite** side of the main
  stack (`overlayDimSide: opposite`).
- Channelizing: discrete **unfilled** markers (FillMode 0), color 6 — not
  filled squares (fill+outline reads as double) and not a TWZCD_P polyline.
- Downstream taper cones are **diagonal**: first shares roll-ahead Y, last at
  far lateral, middle interpolated (`downstreamRun` note in JSON).
- Work-area hatch: closed lane + closed paved shoulder; unfilled boundary
  with visible hatch — not a solid orange blob.

## Visual QA checklist (before asking the engineer)

After scorecard pass + `run_visual_qa_captures` (or equivalent frames):

1. Dim length above / feature name below / X-centered on the span.
2. PV in the roll-ahead bay (front at roll-ahead upstream end); no AP/PV overlap.
3. Channelizing stops where the sheet shows; markers readable, not giant cones.
4. Workspace hatch covers work area only (not buffer / roll-ahead occupancy).
5. Each roadside sign once (watch for duplicate assemblies on re-place).
6. NYW8-33 called out as handoff if not mounted.
7. `reflect_sheet_build` if scorecard or visual misses — cite `primitiveId` /
   `reqId` from the placement registry.

In the in-MicroStation chat agent, `run_visual_qa_captures` /
`run_sheet_build` attach the four frames as **vision + panel SCREENSHOT**.
Review those frames; do **not** call `capture_view` (MCP-only). Use
`view_drawing` only for an extra ad-hoc look.

Do **not** burn iterations on wide `find_elements_near` fishing after
geometry is placed.

## Do-not / common failures

| Failure | Fix |
|---|---|
| Drop Shoulder Taper because a chat hint said skip | Sheet PDF + JSON win — place it |
| Invent Vehicle Space dim/label | Not on this sheet (`annotations.notLabeled`) |
| TWZCD_P polyline channelizing | Use marker representation (JSON) |
| Re-ask locked speed/area_type | `get_locked_designer_inputs` / `get_required_designer_inputs` (skip `locked[]`) |
| Offer 60 mph or invent area_type | Table 311-02/03: 25–55 only; area type is required. Use spec `inputs[].allowed`. |
| Ask engineer to click 38 ft off centerline | `propose_corridor_source` / `lock_corridor_path` / `snap_work_area_to_path`. Lateral is `resolve_sheet_lateral`. |
| Freestyle corridor after order table | `run_sheet_build` / `assemble_corridor` |
| Free `adjust_view` instead of scripted QA | `run_visual_qa_captures` after scorecard |
| Paint sign faces white/orange | `set_sign_attributes` only |
| Declare complete without scorecard + frames | Gate (g) in the WZTC prompt |
| Trust that a passing scorecard means dimensions are visible | Fixed 2026-08-10 (global, not sheet-specific): `ExecPlaceDimension` in `WZTCExec.bas` was restoring the shared `ny_Plan` DimensionStyle's `ShowSecondaryText` right after assigning it, which corrupted an earlier dimension's rendering whenever a later dimension in the same batch reused the style — every dimension but the last in a batch came out invisible (no line/arrows/text) even though `get_elements_range`/the placement registry looked completely normal. Fixed by not restoring it. If dimensions ever look invisible again despite a clean scorecard, actually zoom in and look — the registry/COM range alone won't catch it. See `dev-notes/agent-log.md` 2026-08-10 entry for the full root-cause writeup.
| Call `place_sheet_geometry` directly without `align_idxs` and trust the hatch is there | Fixed 2026-08-10: default now comes from the sheet's own declared alignments, not a hardcoded `[1]`. Still pass `align_idxs=[1,2]` explicitly if you want to be sure, or re-run via `get_geometry_scorecard` to confirm `hatch` is in `placed.byKind`. |
| Arrow panel floating at a bare lateral offset, no post | Fixed 2026-08-10: `place_cell_on_post` stem + panel. Base must be the **perp tip** (not alignment center) or the whole assembly sits ~40–50 ft short of diamond signs (`mountingStyleNote`). Never add TWZSGN_P at the tip — it stacks on the cone. |
| G20-2 label missing or size-only | Fixed 2026-08-10: two-line TEXTEDITOR path (code then size), same as other MUTCD signs. Size-only and size-first TEXTEDITOR both failed engineer QA. |
| G20-2 face missing black inner border ("grouped hole") | Fixed 2026-08-10: SF_P nested cell must be color 240; library place can leave it at 6. `FixG20FaceBlackHole` after place. Compare to engineer reference if unsure. |
| Doubled/duplicate channelizing markers at taper junctions | Fixed 2026-08-10: `placed_points` XY dedup across runs (`runsSharedBoundaryNote`). |
| Channelizing looks "double rendered" with no stacked IDs | Fixed 2026-08-10: markers were FillMode=1 (filled). Use FillMode 0 (`representation.fillModeNote`). |
| Downstream taper cones in a flat row / wrong side of centerline | Fixed 2026-08-10: `downstreamRun` diagonal; then re-fixed same day for channelizing-line align (offset 0 → −lane_width on Align2). |
| EB right-lane hatch lands north of yellow | Align1 points west; `outward_sign=−1` → +Y. Use `outward_sign=+1` for south/EB-right (demo 2026-08-10). |
| Real-road striping vanishes on rebuild | `place_polyline` roads are journal-owned; `assemble_corridor(force=True)` deletes them. Place corridor **after** the sheet build (or omit force when aligns empty). |
| Channelizers on fog line / “middle of road”; taper does not close right lane | Fixed 2026-08-10: alignment = left edge of closed lane (channelizing). Longitudinal offset **0** (not +lane_width). Lane taper tip at +lane (outer travel), toe at 0; shoulder tip at +lane+shoulder (EOP). |
| Real-road demo sat on wrong half of undivided strip | `place_two_way_highway(x1,y1,…)` is the **first travel outer edge**, not yellow center. On +X/`side=right`, EB right dash is `Y_north_outer − (2·lane + yellow_gap + lane)`. Prior demos used `Yc−12` (north dash) — looked like cones through the middle. |
| Duplicate arrow panel | `place_sheet_geometry` places AP once (`count=1`); clear before rebuild. |
| G20-2 on wrong roadside / near yellow | Align2 tan flips `_outward_unit`. Lock `closed_outward` via `resolve_sheet_lateral` and tip G20 on the **same closed shoulder** as W20s (not opposite roadside). |
| White align + perp ticks clutter the plan | `run_sheet_build` always calls `delete_construction_guides` after geometry (straight and curved), before visual QA. Manual re-call if ticks remain. |
| Rotate sign faces to corridor tangent on a curve | **Wrong for MUTCD faces.** Faces stay view-horizontal. Dim **name labels** follow the curve tangent, then **flip 180°** if more than 90° CW or CCW from view-upright (upside-down lettering). |
| Feature name labels upside-down on a westbound/southbound tangent | `_text_angle_deg` keeps the tangent, then folds into (−90°, 90°]. ±90° is kept (northbound L-bend). |
| Building on top of a prior sheet / stacked labels | Ledger + `check_build_overlap` (caution, not block). Same sheet+origin → `clear_plan_elements` first. Scorecard fails on live stacked duplicates (Tier 1 hash). |
| Signpost T (TWZSGN_P) 90° off on a bend | Post used view angle like the face. Rotate TWZSGN_P with **travel** tangent (`postAngleDeg`): Align1 tan is −travel, Align2 tan is +travel. Arm of the T toward the next downstream sign; stem toward upstream; T stays on the curve. Faces stay view-horizontal. |
| Protective vehicle faces the wrong way | TWZWVA_P is placed at the same XY with `angleDeg = tangent + 180` (rotate 180 about cell center). Straight and curved. |
| Curved corridor built as a straight chord between edge picks | Pass `path_vertices` (closed-lane / first-travel outer polyline) to `resolve_sheet_lateral` + `run_sheet_build` / `assemble_corridor`. Straight chord is only for E–W abstract ticks. |
| Real-road “four-way” / multilane with no striping | After sheet build, call `place_two_way_highway(…, vertices=path)` (or straight x1..y2). Do not FINAL on ticks-only when the engineer asked for a real road. |
| Dims cut through the highway / show wrong lengths on a bend | **Engineer (2026-08-13 / 08-14):** Match the L-bend. Dims always **outside pavement**. Inside of an S-bend: Arc Size at `r-15`. A 45° SizeArrow (S-curve BUFFER) must re-apply `DimHeight` **after** ny_Plan style or the dim has no line (range = tips only). Always pass sheet-length override text on SizeArrow. |
| White stem misses the sign face on a diagonal C/S curve | Stem to orange (color 6) inward edge on the perp ray, plus 1.5 ft into the fill. G20 inner-hole / construction verts sit short of the orange — do not snap those. |
| Overlay dim (SHOULDER TAPER) drawn across the travel lanes | `annotationStyle.overlayDimSide="opposite"` is a **printed-sheet** convention — on the schematic the other side is blank paper. On a **real road** the alignment is the closed-lane edge, so an unconditional flip puts the overlay dim through the pavement. Live C-curve build 2026-08-13: SHOULDER TAPER tipped at align−20 (r=3018, between lane line and yellow) while every other dim tipped at align+20 (r=3058, on the EOP). `compile_plan` now keeps overlay dims on the SAME roadside whenever a real-road `tip_half_len_ft` is locked, and clears the main dim column by `dimOutward*2` instead of crossing the road. Schematic builds (no `tip_half_len_ft`) keep the printed flip. Tests: `test_overlay_dim_stays_off_pavement_on_real_road` / `test_overlay_dim_still_flips_on_schematic_build`. |
| Work-area hatch looks like a box / spills out of the curved lane | Hatch boundary densifies along `workBayVertices`; drawn stripes clip to the shape (not the AABB). Alignment = left edge of **closed outer** lane (same offset as straight: `2·lane + yellow_gap + lane` from first-travel outer on undivided 4-lane). Width = closed lane + shoulder. `CHAN_OFF=lane` reads as a center closure. |
| Sign assemblies disconnected on a curve | Do not freeze `closed_outward` from WA-mid for every station. Tip each sign with local Align1-equivalent outward (`−tan` on Align2). Faces stay view-horizontal. Posts follow local travel tangent. |
| Sibling C / S / straight builds wipe the L-bend | `clear_plan_elements` / `assemble_corridor(force=True)` with aligns already ready deletes the last journaled sheet. For side-by-side family builds: session-reset only (`PlanSession.reset`, no CLEAR_PLAN), fence-wipe **only the new AABB**. Helper: `scripts/build_619311_curve_family.py`. |

## When to edit this file

**Required after every live 619-311 fix or engineer QA correction** (same bar
as `.cursor/rules/sheet-spec-sync.mdc`):

1. Encode anything the compiler/executor must obey in `619-311.json`
   (notes on the affected `signs` / `symbols` / `representation` item).
2. Append the human tip + Do-not row here.
3. Append `dev-notes/agent-log.md` for the cross-tool bridge.

Do **not** leave a preference only in chat or only in `agent-log.md`.
The in-MicroStation agent loads `buildGuide` via `get_sheet_requirements` /
`get_sheet_build_guide` — if it is not here, the next turn will rediscover it.
